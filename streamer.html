방송 화면에 오버레이 띄우기 — 스트리머 가이드

채팅창·후원 알림처럼 브라우저 창을 방송에 한 겹 얹는 표준 방식입니다. 최초 1회만 설정하면 다음 방송부터는 자동입니다 — 경기 없으면 투명하게 대기 → 경기 시작 시 자동 표시 → 세트 전환 자동.

송출용 주소

https://dugout26.github.io/lck-overlay-assets/freecshot.html

프릭샷2 (창 캡처 + 크로마키)

  1. 크롬에서 위 주소를 엽니다 → 초록 배경 창이 뜹니다
  2. 프릭샷2 화면 구성에서 창 캡처로 그 크롬 창을 추가합니다
  3. 크로마키를 켜고 초록색을 제거합니다 (아이콘 색이 갉히면 유사도를 낮추거나 주소 뒤에 ?bg=FF00FF)
  4. 레이어 크기를 게임 중계 화면과 1:1(16:9)로 맞춥니다 — 선수 클릭 존이 자동으로 정렬됩니다

OBS (브라우저 소스 — 크로마키 불필요)

  1. 소스 추가 → 브라우저 → 주소 뒤에 ?bg=transparent를 붙여 입력, 1920×1080
  2. 게임 화면 위에 꽉 차게 배치하면 끝 — 배경이 진짜 투명이라 색 손실이 없습니다

방송 중 조작

기본은 방해금지 모드 — 방송에 아무것도 안 보이는 클린 상태로 시작합니다.

선수 룬 보여주기크롬 창에서 그 선수 위치 클릭 (마우스 올리면 이름 태그) · 재클릭으로 닫기
전체 정보 패널Alt + K (방해금지 ↔ 패널 전환)
잠깐 다 숨기기Alt + L

클릭·단축키는 방송 화면이 아니라 열어둔 크롬 창에서 합니다 (창이 활성 상태여야 함). OBS 브라우저 소스 방식은 소스 우클릭 → "상호작용" 창에서 조작하세요. 시청자에게는 결과(룬 팝업)만 보입니다.

주소 옵션

조합 가능 — 예: ?bg=transparent&delay=-30

?bg=transparent배경 투명 (OBS 브라우저 소스용) · ?bg=FF00FF처럼 색 지정도 가능
?delay=초표시 시점 조정 (기본 0 = 가장 최신 데이터, 라이엇 공급 특성상 실경기 대비 ~30초)
?dnd=0방해금지 대신 패널 모드로 시작
