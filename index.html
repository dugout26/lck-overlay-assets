SOOP 실방송 위에 오버레이 띄우기 (확장 설치 없이)

라이엇 API가 브라우저 교차 출처 요청을 허용하고 SOOP에 CSP가 없어서, 스크립트 주입만으로 라이브 오버레이가 동작합니다. 라이브 LCK·챌린저스 경기가 있으면 자동 감지하고, 없으면 최근 경기를 리플레이 모드(15분 지점부터 실시간 재생)로 보여줍니다.

먼저 보기 — 30초 데모

방법 1 — 북마클릿 (추천 · 최초 1분 설정, 이후엔 클릭 한 번)

  1. 코드 복사 — 아래 버튼을 누르세요.
    복사됨!
  2. 북마크로 등록 (최초 1회)
    ① 북마크바가 안 보이면 Ctrl+Shift+B (맥 ⌘⇧B)로 켜기
    ② 북마크바 빈 곳에 마우스 우클릭 → "페이지 추가" (또는 북마크 관리자에서 "새 북마크 추가")
    ③ 이름: LCK 룬 오버레이 / URL 칸에 방금 복사한 코드 붙여넣기 → 저장
  3. 사용하기 — SOOP에서 경기 화면을 연 상태에서 방금 만든 북마크를 클릭
    · 라이브 중계 → 경기 자동 감지 · 공식 다시보기 → 시간 자동 싱크 · 워치파티 → 시계 자동 인식
    · 끄기: 페이지 새로고침 (또는 오버레이의 × / 단축키 Alt+L)
    · 항상 최신 버전이 실행되므로 업데이트는 신경 쓸 필요 없음

기능 안내

패널 탭 4개

  • 선수 — 10인 카드(레벨·KDA·CS·골드·체력). 카드 클릭 → 룬 풀페이지(키스톤·메인/서브 트리·스탯 조각)와 아이템, 스킬 마스터 순서·킬관여·와드. "↔ 라인 상대 비교"를 누르면 같은 포지션 두 선수의 룬과 레벨·CS·골드 격차를 나란히 보여줍니다.
  • 룬 — 10인 전원의 룬을 아이콘으로 한눈에. 아이콘에 마우스를 올리면 이름, 행 클릭 시 상세로 이동.
  • 지표 — 골드 · 딜 비중 · KDA · CS/분 · 킬관여 · 와드를 팀별 순위로 비교.
  • 골드 그래프 — 팀 골드 차이 추이 (앞선 팀 색으로 표시).

조작

  • 헤더를 잡고 드래그로 이동 · 헤더 ×로 작은 필로 접기 · 필 옆 ⊗로 완전 숨김
  • 방해금지 모드(설정에서 켬) — 패널이 사라지고, 중계 화면 좌우의 선수 자리를 클릭하면 그 선수 룬만 팝업으로.
  • 설정(톱니) — 경기·세트 선택, 게임 시간 싱크, 모드(개인 시청/스트리머 송출), UI 크기(자동), 딜레이 보정, 투명도, 표시 항목 켜고 끄기, 게임 화면 영역·선수 존 위치 맞추기.

자동으로 되는 것들 — 라이브 경기 감지 · 공식 다시보기 시간 싱크(시킹 포함) · 워치파티 게임 시계 인식 · 밴픽 구간 픽 스포일러 차단 · 라이브 되감기 추적

단축키 (SOOP 탭에서, 채팅 입력 중엔 무시됨)

Alt + L오버레이 전체 표시 / 숨김
Alt + K방해금지 모드 켜기 / 끄기

알려진 문제 (v0.2.7)

  • 방해금지 모드의 클릭 존·팝업 크기가 실제 선수 바와 안 맞을 수 있음 — 설정 → "게임 화면 영역·선수 존 위치 맞추기"로 보정 가능. 크기가 이상하면 제보 부탁드립니다
  • 워치파티 시계 자동 인식이 리플레이 장면·저화질에서 일시적으로 끊길 수 있음 (자동 재탐색으로 복귀)
  • 녹화본 리워치 파티는 시계 인식 실패 시 설정 → 게임 시간 수동 입력이 필요할 수 있음
다시보기·워치파티 시청 팁 — 시간 맞추기
시계 자동 인식이 안 붙으면: 게임이 진행 중인 구간에서(밴픽·대기 화면 X) 화면 속 게임 시계를 보고 설정(톱니) → 게임 시간에 정확히 1회 입력하세요 (예: 15:45). 그 세트 안에서는 이후 실시간 재생·시킹 모두 자동으로 따라갑니다. 세트가 바뀌면 한 번만 다시 입력하면 됩니다.
